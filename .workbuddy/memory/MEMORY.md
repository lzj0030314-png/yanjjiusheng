# 项目长期记忆

## 标准来源约定
- **所有抗震韧性评价相关的标准/规范，均以 `D:\研究生新\抗震标准.pdf` 为准**（GB/T 38591—2020《建筑抗震韧性评价标准》）。用户明确要求"以后的所有标准都来自这里面"。
- 该 PDF 文本层编码损坏（ToUnicode 缺失），需用 PyMuPDF 渲染 PNG + Windows 内置 OCR（zh-Hans-CN）才能读取中文；高清大图会超出 Windows OCR 像素上限，用 200 DPI 即可。
- 本标准只给方法学 + 系数表（表 C.7/C.8/C.9/C.10/C.11/C.12、表 E.4/E.5/E.6/E.7/E.8/E.9/E.10）；具体构件易损性数据库（编码 A.98.* / B.01.* 等 medians/betas）**不在本标准 PDF 内**，来自配套"易损性数据库"（应在用户端使用手册中）。

## 关键核对结论（大中小通用.py）
- 与标准一致：评级阈值（表5/6/7）、伤亡名义率（表4）、N_max=0.026·A_f、蒙特卡洛≥1000 次。
- 主要偏差：`大中小通用.py` 对修复费用、人员伤亡取 `np.mean`，但标准 9.4.1/A.5.4 要求三项指标均用"84% 保证率的对数正态拟合值"（代码仅时间用了 percentile(84)）。其余见检查报告。
