### 【严重-2】**表3 楼层破坏等级函数已实现但 evaluate() 仍调用旧逻辑**
- **标准**8.2.2+式(14)：每层先用表3规则判定**一个**楼层破坏等级 r_f ∈ {I,II,III,IV,V}（分结构与可致伤亡非结构两组取大值），然后 `M_H = Σ_{r=1..5} r_{lr} × (该等级人口)`。
- **代码**：`_struct_floor_level` 和 `_nonstruct_floor_level`（表3 规则）实现正确，但 evaluate() 内**从未调用**，第 448–459 行改用：
  ```python
  for r_idx in range(5):
      ratio_k = struct_ds[r_idx] / struct_total       # ← 用结构构件 DS 比例当"楼层人口分布"
      A_r_k = floor_area * ratio_k
      sim_inj += r_hr * pop_density * A_r_k
  ```
  即把楼层人口按"结构构件各 DS 的数量占比"分摊到 5 个等级，且**只用结构构件**，完全忽略 8.2.2(b) "可致伤亡的非结构构件"。
- **后果**：人员伤亡被错误地按结构 DS 比例"平均化"——大量处于 DS0/DS1（完好/轻微）的人口被分配到 IV/V 级高伤亡率上，结果与标准不一致；且未取结构/非结构两组中较大值。
- **修改**：evaluate() 第 448 行改为先调用 `_struct_floor_level(struct_比例)` 和 `_nonstruct_floor_level(nonstruct_比例)` 取得结构楼层等级 R1 和非结构楼层等级 R2，取 `r_f = max(R1, R2)`，再用 `_CASUALTY_RATE[r_f - 1]`（注意表函数 key 是 0..4 而表3 返回 1..5，需修正 KeyError 隐患）算 `M_H += r_lr × pop_density × floor_area`。
- **附带 Bug**：`_CASUALTY_RATE` / `_CASUALTY_RATE_TABLE` 用 0..4 索引（0=I, 1=II, ..., 4=V），但 `_struct_floor_level` 返回 1..5（1=I, ..., 5=V）。一旦调用表3函数即会触发 KeyError 或错位。

### 【严重-5】**修复费用仍为"解析期望"而非 A.5.2 要求的"损伤状态采样"**
- **标准**A.5.2：对于一次蒙特卡洛模拟，应**判定建筑损伤状态**（即对每个构件按其破坏状态概率**采样**一个 DS）；A.5.3：每次模拟据此计算 R_T、T_tot、M_H。
- **代码**第 368–393 行 `_analytic`：对每个构件计算 `exp_c = Σ_j P(DS=j) × loss_ratio_j × cost × repair_factor × qty`（对 DS 概率**积分取期望**），不是采样。
- **后果**：1000 次模拟中 EDP 随机，但每构件 DS 用期望——序列是"1000 个期望值"，标准要求是"1000 个抽样实现值"。两者的 84% 分位统计性质不同（抽样实现的方差更大，84% 分位会更高，偏保守；期望序列方差小，84% 分位偏低，**偏乐观**）。
- **修改**：用 `np.random.choice(len(probs), p=probs)` 采样一个 DS j，按 j 取 `loss_ratios[j-1]`、`repair_factors[j-1]`、`repair_times[j-1]` 计算当次实现的费用/工时。

### 【中等-6】**楼层影响系数 n_S 重复应用且语义错**
- **标准**式(6)：`Q_{i,k} = Σ_j [Q_L × n] × ξ_{T(i)} × λ_{T(k)}` —— 楼层影响系数 λ_{T(k)}（表C.13）**只乘在工时**上，且按**楼层 k 所在位置**取值（C.13：1~3层 1.00、4~6层 1.05、7~12层 1.08、12层以上 1.10）。
- **代码**：
  - 第 463 行 `Q[k] *= floor_influence`（按 Excel 楼层影响系数列乘在工时上）—— ✅ 正确
  - 第 478/491/505 行 `sim_floor_times = (T1+T2)*n_S` / `time_bldg = max((T1+T2)*n_S)` / `ft_tot = (T_S1+T_S2)*n_S` —— 又**整体乘 n_S**
  - 第 284–288 行 `n_S` 是按**总层数 nf** 取的"建筑级"系数（nf>=12→1.10、7~11→1.08、4~6→1.05、否则1.00）
- **问题**：
  1. 双重计入楼层影响（Q×floor_influence 后整体又 ×n_S）
  2. n_S 是"按总层数"而非"按楼层位置"——与 C.13 语义不符（C.13 是 per-floor-position，3 层建筑每层 λ=1.00；15 层建筑 1~3 层 1.00、13~15 层 1.10）
- **后果**：本算例 3 层 n_S=1.00，无数值影响；4 层+建筑会重复放大约 5~10% 时间。
- **修改**：删除所有 `* n_S`；C.13 楼层影响系数已通过 `Q *= floor_influence` 体现（前提：Excel 楼层影响系数列按 C.13 取值）。如果 n_S 还要用作整体调整，注释说明并改用式(6) 的 per-floor λ。

### 【中等-7】**calc_84th 改为经验分位，与 A.5.4"对数正态拟合"不符**
- **标准**A.5.4：采用**对数正态分布模型拟合**各项指标集合，并采用具有 **84% 保证率**的拟合值。
- **代码**第 155–161 行：直接用 `np.percentile(arr, 84)` 经验分位，未做对数正态拟合。
- **后果**：对于含较多 0 值的样本（时间/伤亡），经验 84 分位 ≠ lognormal 拟合 84 分位；对数正态拟合对极端值更平滑。555 版的 `exp(mean(log)+std(log))` 更接近 A.5.4。
- **可接受理由**：时间/伤亡常含 0（无破坏→0 费用/0 工时/0 伤亡），`log(0)` 无法做对数正态拟合，所以采用经验分位是务实工程选择。但严格 A.5.4 要求"对数正态拟合"，可考虑：用 0 替换/截断 + 加微小正值后做 lognormal 拟合，或对非零子集做 lognormal 拟合再回填。
- **修改**：恢复 555 版的 `exp(mean_log+std_log)`（自动跳过 0），或对非零值做对数正态拟合后取 84% 分位。

### 【中等-8】**加速度 EDP 矩阵包含屋顶行但 drift 不包含——矩阵维度/协方差不一致**
- **数据**：`结构响应` sheet 行结构（header=0 后 iloc 索引）：

  - 实际：默认 header=0 → sheet 行 0 作 header → df iloc 0 = sheet 行 1 = 地震波标题行
  - df iloc 1 = sheet 行 2 = 楼层0（屋顶，drift 全 NaN，accel 有数据 4.19）
  - df iloc 2..4 = sheet 行 3..5 = 楼层1,2,3
- **代码**第 104–110 行：

### 【轻微-11】**B.01.A.A.A.001 2-中位值模型 + 完好当损伤状态**
- **标准**：非结构构件损伤状态 1~3 级（+完好 = 4 状态），应有 3 个中位值。
- **代码**第 87–95 行：medians=[0.0338, 0.0383]、loss_ratios=[0.0, 1.00]、repair_factors=[0.0, 1.67]、repair_times=[0.0, 0.216]——把"完好"当一个损伤状态。
- **后果**：与标准损伤状态分级不匹配；1.67 修复系数在 E.5 中无完全对应（玻璃幕墙架式单片夹胶钢化 1.67/1.40/1.40 最接近）。
- **修改**：按 E.4/E.5 选用的非结构构件（如某类幕墙/楼梯），补齐 3 个中位值与对应损失/修复系数/工时。

### 【轻微-12】**_CASUALTY_RATE 与 _struct_floor_level 索引不匹配（潜在 KeyError）**
- `_CASUALTY_RATE` / `_CASUALTY_RATE_TABLE` 用 key 0..4（0=I, 1=II, ..., 4=V）
- `_struct_floor_level` / `_nonstruct_floor_level` 返回 1..5（1=I, ..., 5=V）
- **当前 evaluate() 不调用表3函数，未触发**；但一旦按【严重-2】修改后接入表3函数，会立即触发 KeyError 或错位。
- **修改**：把表3函数返回值改为 0..4，或 _CASUALTY_RATE key 改为 1..5，统一后接入。

### 【轻微-13】**B.01.A.A.A.001 与 B.98 "无方向构件"用 max(dx,dy) 或 sqrt(dx²+dy²)**
- **标准**：无方向性构件用哪个 EDP 未明确；工程实践有 max、sqrt(x²+y²) 等方案。
- **代码**：B.98 用 `max(dx, dy)`；B.01.A.A.A.001 用 `np.sqrt(dx**2 + dy**2)`；B.01.B 用 `np.sqrt(ax**2 + ay**2)`。
- **后果**：sqrt 合成比 max 偏小（单方向占优时≈主方向值，双向等强时=1.41×主方向），需核实标准规定。
- **修改**：核实 4.x 节"基本规定"关于双向地震作用的规定（可能要求"取不利方向"），统一处理。

### 【轻微-14】**X/Y 方向分别评价取不利值？需核实**
- **标准**第 4 章（基本规定）可能要求建筑抗震韧性评价应**按两个主轴方向分别进行，取评级较低者**（不利方向）。
- **代码**：将 X、Y 方向 EDP **合并**评估（cost_str = cost_x + cost_y; time = max(W1_x, W1_y) 等等），未做"分别评价取不利"。
- **后果**：若标准要求分方向评级，合并会高估建筑评级。
- **修改**：核实 4.1/4.2 条文，若要求分方向则分别跑 X、Y 两次评价取 min 等级。

## 五、需要用户确认的事项

1. **"楼层影响系数"列含义**：代码现在用同一列同时供费用（C.9）和时间（C.13），且又额外加了按总层数取的 n_S。若按 C.13 严格按楼层位置取值，Excel 楼层影响系数列应按楼层填 C.13 值（1~3 层 1.00、4~6 层 1.05、7~12 层 1.08、12+ 层 1.10），然后删除 n_S 重复。
2. **构件→工种映射**：5 个构件的"所属修复工作内容"应从易损性数据库读取（手册第 149 行），代码硬编码可能与数据库实际分类不一致。
3. **式(14) 中 k=1..5 的解读**：标准原文 `Σ_{k=1}^{5}` 上限是 5，结合 8.2.2（每个楼层定一个破坏等级），合理解读为 k=破坏等级 r=1..5，A_{k,l}=第 l 楼层中处于 r=k 级的面积。如确认此解读，evaluate() 伤亡逻辑需要按 8.2.2 重构。
4. **式(11) vs 7.2.1(c) 文字的 W5 归属歧义**：式(11) 把 W5 列入阶段1 max；7.2.1(c) 文字把 W5 列入阶段2。本报告与代码均按文字版（阶段1=结构+楼梯，阶段2 链含 W5）。如用户希望严格按式(11) 执行，需相应调整 time_s1 含 W5、time_s2 不含 W5。
5. **残余变形角 1/200**：本算例 3 层建筑通常残余变形很小，但建议在代码中加入读取与判断逻辑以符合 A.3。
6. **EDP 矩阵是否应包含屋顶**：手册说含 0 号楼层（屋顶）。当前代码 drift 不含、accel 含——需统一。
